# 🚀 Job Search Copilot

A lightweight, real-time application tracking dashboard built with Python and Streamlit to streamline job searching, track application statuses, analyze ATS keyword matches, and generate quick interview prep sheets.

---

## ✨ Features

* **⚡ Real-Time Gmail Sync:** Auto-scans inbox and sent folders for active application emails using Python's IMAP library.
* **🎯 ATS Keyword Matcher:** Compares job descriptions against your master resume to highlight matched skills and missing critical keywords.
* **⚡ 1-Minute Interview Cheat Sheet:** Generates structured technical focus points, likely behavioral questions, and candidate questions for upcoming interviews.
* **📊 Analytics & Metrics:** Displays live status badges and metrics across applied, interviewing, offered, and international roles.
* **📥 One-Click Data Export:** Export tracked job applications instantly to `.csv` or `.xlsx` files.

---

## 🛠️ Tech Stack

* **Framework:** Streamlit
* **Data Processing:** Pandas
* **Database:** SQLite & SQLAlchemy
* **Language:** Python 3.x
